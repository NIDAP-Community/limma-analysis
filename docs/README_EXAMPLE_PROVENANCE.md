# README Synthetic Example Provenance

The README example uses only the redistributable six-sample fixture committed in
`test_data/`. It is not derived from a patient cohort and contains intentionally
shifted values for `Gene1` through `Gene3` in group `B`.

## Invocation

```bash
container/smoke_test.sh limma-analysis:validation-9f57243
```

## Expected result

The `B-A` contrast returns positive log fold changes of 1.9, 1.8, and 1.7 for
`Gene1`, `Gene2`, and `Gene3`, respectively. The associated variance diagnostic
is written to `figures/variance_diagnostic.png`; it was generated by the local
AMD64 smoke test on 2026-10-27.

The example demonstrates result-bundle shape and contrast direction only. It
does not establish a biological or clinical conclusion.
